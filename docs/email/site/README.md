# launchpad-colors.netlify.app

The "Pick your colors" mock: five colorways, Web/Mobile, Light/Dark, four screens.
Works without JavaScript (radio buttons + CSS). `#1`–`#5` or `#hunter` etc. opens one option.

Netlify project: launchpad-colors (site id a8009805-ded8-4f9f-91ee-9151b6d5a892). Redeploy this
folder as-is; there is no build step. `../build-colors-mock.py` regenerates `index.html`
(`WEB=1`) from screenshots in an `img/` folder next to it.
